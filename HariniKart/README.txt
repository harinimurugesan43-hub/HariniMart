HARINIMART - BASIC ONLINE SHOPPING WEBSITE

Included:
- Email + password login UI
- Continue with Google button (demo/local)
- Product listing
- Search products
- Product details
- Add to Cart
- Quantity + / -
- Remove from Cart
- Buy Now
- Checkout form
- Payment method selection
- Order success message
- Logout
- Responsive mobile design
- Cart saved in browser localStorage

HOW TO RUN:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html.
4. For easiest running, install the VS Code "Live Server" extension.
5. Right-click index.html -> "Open with Live Server".

IMPORTANT:
This is a frontend demo. Email/password login is local/demo only.
The Google button is also a demo. For real Google authentication,
connect Firebase Authentication and add your Firebase configuration.

No real payment is processed by this version.
